# Specs

One folder per domain (`catalog/`, `cart/`, `checkout/`, `account/`,
`admin/`, …). Per feature:

- `<feature>.md` — WHAT/WHY only, referencing the relevant mockup(s) in
  `Docs/design/mockups/`.
- `<feature>-implementation-plan.md` — HOW.

See the Implementation Workflow in the root `CLAUDE.md`.
